Free Flip Clock Widget for Your Website

Paste one line of code and your site, blog or dashboard shows a live flip clock. No sign-up, no script on your page, works in light and dark.

Embed code

Copy this into any page that accepts HTML (WordPress Custom HTML block, Squarespace Code block, Google Sites Embed, Notion embed with the iframe address):

<iframe src="https://open.cait518.cc/stayclock-support/embed/flip-clock.html" width="340" height="170" style="border:0;border-radius:14px" title="Flip clock" loading="lazy"></iframe>
<p style="font-size:12px;margin:4px 0">Clock by <a href="https://open.cait518.cc/stayclock-support/flip-clock-widget-for-website.html" rel="nofollow">Stay Clock</a></p>

Options

Add to the addressWhat it doesExample
?h12=112-hour time with AM/PM (default is 24-hour)flip-clock.html?h12=1
?tz=Area/CityShow a fixed time zone instead of the visitor's own?tz=Asia/Tokyo
?theme=lightLight face (default is dark)?theme=light&h12=1

Combine options with &. Time zone names follow the standard list (for example Europe/London, Australia/Sydney). The clock runs in the visitor's browser and sends nothing back.
